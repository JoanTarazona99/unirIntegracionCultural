# Проект обновления разделов ВКР, посвящённых оценке информационного поиска

Настоящий документ содержит предлагаемую академическую формулировку для обновления методики, результатов, интерпретации, гипотезы и заключения ВКР. Он не является уже внесённой редакцией исходного DOCX-файла. Текст подготовлен на основе воспроизводимых артефактов первичной оценки B3, результатов отдельной разведочной оценки и методологического аудита утверждений ВКР.

## 1. Методика оценки

Качество информационного поиска оценивалось на двух раздельных наборах данных, имеющих различный методологический статус. Результаты этих наборов не объединялись и не рассматривались как единая выборка.

Первичной доказательной базой служила исходная оценка B3 на 36 запросах. В неё вошли 23 запроса на испанском языке, 9 на английском и 4 на русском. Эффективный корпус, сформированный программным модулем `OfficialDocumentLibrary`, включал 18 источников и 44 активных текстовых фрагмента. Для запросов использовались бинарные оценки релевантности: фрагмент либо считался релевантным, либо не включался в соответствующий qrel. Доступные артефакты не позволяют документально подтвердить число аннотаторов, их квалификацию и межаннотаторское согласие для исходного набора из 36 запросов. Поэтому qrels B3 следует описывать как рабочие бинарные оценки релевантности, не приписывая им неподтверждённый статус независимо установленного эталона или экспертной разметки.

В B3 сравнивались пять методов:

1. поиск по ключевым словам (`keyword`);
2. лексический поиск BM25 с расширением запроса;
3. плотный поиск (`dense`) с моделью `paraphrase-multilingual-MiniLM-L12-v2`;
4. гибридный поиск (`hybrid`), объединяющий BM25 и dense посредством Reciprocal Rank Fusion при `rrf_k = 60`;
5. гибридный поиск с переранжированием (`hybrid_rerank`), в котором результаты гибридного поиска дополнительно оценивались кросс-энкодером с учётом языка запроса.

Все методы оценивались при `k = 1, 3, 5`; в настоящем разделе приводятся результаты при `k = 5`. Hit@5 характеризует долю запросов, для которых среди первых пяти результатов присутствует хотя бы один релевантный фрагмент. Recall@5 характеризует долю релевантных фрагментов, указанных в qrels, которые были получены в первых пяти позициях выдачи. Precision@5 отражает долю релевантных фрагментов среди пяти выданных результатов. MRR@5 представляет среднее значение обратного ранга первого релевантного результата с ограничением рассмотрения первыми пятью позициями. nDCG@5 характеризует качество ранжирования с учётом позиций релевантных результатов.

Дополнительно была проведена отдельная разведочная оценка. 132 синтетических запроса были сформированы на основе активных фрагментов корпуса с последующей проверкой структуры и согласованности. Запросы и исходные qrels были получены из тем и шаблонов, а не из независимо собранного потока обращений пользователей. Последующая проверка была выполнена с помощью ИИ. По её итогам 15 записей получили статус `accepted`, 99 — `revised`, а 18 записей со статусом `pending` были исключены. В отдельный набор экспортировано 114 записей: по 38 на испанском, английском и русском языках. Для 44 записей указаны многофрагментные qrels.

Расширенный набор сохраняет синтетическое происхождение запросов и qrels. Проверка с помощью ИИ не является независимой человеческой аннотацией. Метаданные набора явно фиксируют `used_for_official_metrics=false`, `official_evaluation_eligible=false` и `human_review_completed=false`. Следовательно, данный набор не является официальным оценочным набором или независимо подтверждённым эталоном, а его результаты должны использоваться только как разведочные данные, дополняющие, но не заменяющие первичную оценку B3.

Оценка выполнялась в зафиксированном Windows CPU-окружении с семенем 42. Основные версии программных компонентов приведены ниже.

| transformers | 4.57.6 |
| huggingface-hub | 0.36.2 |
| rank-bm25 | 0.2.2 |

Для нейросетевых компонентов использовались локальные snapshots с зафиксированными идентификаторами версий:

| --- | --- | --- |
| Плотный поиск | `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` | `e8f8c211226b894fcb81acc59f3b34ba3efd5f42` |
| Переранжирование ES/RU | `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1` | `1427fd652930e4ba29e8149678df786c240d8825` |
| Переранжирование EN | `cross-encoder/ms-marco-MiniLM-L-12-v2` | `7b0235231ca2674cb8ca8f022859a6eba2b1c968` |

Перед оценкой была выполнена предварительная автономная проверка, подтвердившая доступность локальных snapshots, получение конечных числовых значений и корректную форму выходов плотной модели и обоих кросс-энкодеров. Предварительная автономная проверка зафиксировала `probe_network_attempts=0`, а непосредственный запуск оценки — `evaluation_network_attempts=0`. Все пять методов завершили выполнение без ошибок retrieval. В расширенной оценке `fallback_count=0`, поэтому результаты нейросетевых конфигураций не являются скрытой подстановкой BM25.

Для `hybrid_rerank` в расширенном запуске зарегистрировано 2 280 реальных предсказаний переранжировщика. Телеметрия подтверждает использование обоих кросс-энкодеров: мультиязычной модели для запросов на испанском и русском языках и отдельной модели для английского языка. В первичной оценке B3 было зарегистрировано 720 предсказаний переранжировщика.

Публикация расширенной оценки выполнялась транзакционно. Каждый JSON- или CSV-артефакт сначала сериализовался во временный файл в том же каталоге, синхронизировался и заменялся атомарно. После проверки шести артефактов подготовленный каталог публиковался целиком без перезаписи существующего результата. Опубликованный набор включает полный JSON результата, глобальный CSV, CSV трасс запросов, CSV по языкам, CSV по категориям и JSON парного bootstrap. Такая процедура защищает опубликованный результат от частичной записи, но сама по себе не устраняет методологические ограничения набора данных.

Воспроизводимость первичной оценки дополнительно подтверждена тем, что 75 глобальных агрегатов запуска B3 совпали с предшествующим запуском B2 с абсолютной погрешностью не более `1e-12`. Этот вывод относится к зафиксированным данным, локальным snapshots, параметрам и проверенному окружению; он не означает автоматической воспроизводимости в произвольной программной или аппаратной конфигурации.

## 3. Результаты на исходном наборе из 36 запросов

Глобальные результаты первичной оценки B3 при `k = 5` представлены в таблице.

| Метод | Hit@5 | Recall@5 | Precision@5 | MRR@5 | nDCG@5 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Keyword | 0.361111 | 0.263889 | 0.083333 | 0.304167 | 0.251116 |
| BM25 | 0.500000 | 0.430556 | 0.144444 | 0.406019 | 0.384415 |
| Dense | **0.805556** | **0.777778** | **0.227778** | **0.689815** | **0.696087** |
| Hybrid RRF | 0.694444 | 0.666667 | 0.200000 | 0.487037 | 0.513971 |
| Hybrid rerank | 0.777778 | 0.736111 | 0.205556 | 0.632870 | 0.640471 |

На исходном наборе плотный поиск показал наибольшие глобальные значения Hit@5, Recall@5, MRR@5 и nDCG@5. Кроме того, его значение Precision@5 также было наибольшим среди пяти методов. Следовательно, результаты B3 не подтверждают утверждение о глобальном превосходстве гибридной схемы над плотным поиском.

Для `hybrid_rerank` были получены более высокие описательные значения показателей, а парный bootstrap подтвердил улучшение MRR@5 и nDCG@5 относительно BM25. Для MRR@5 разность `hybrid_rerank - BM25` составила 0,226852 при 95%-м доверительном интервале [0,077766; 0,377789] и двустороннем `p = 0,0042`. Для nDCG@5 разность составила 0,256056 при 95%-м доверительном интервале [0,116496; 0,398848] и `p = 0,0010`. Парный bootstrap включал 10 000 повторных выборок и использовал семя 42. Bootstrap-сравнение с `dense` не проводилось.

Статистическая интерпретация должна быть ограничена выполненным сравнением BM25 и `hybrid_rerank`. Bootstrap-сравнение `hybrid_rerank` с `dense` не проводилось. Поэтому нельзя утверждать статистическое превосходство гибридного переранжирования над плотным поиском. Напротив, описательные глобальные значения B3 показывают лидерство `dense`.

## 4. Разведочная оценка на расширенном наборе из 114 запросов

| Keyword | 0.526316 | 0.441520 | 0.121053 | 0.433626 | 0.406400 |
| BM25 | 0.684211 | 0.589181 | 0.159649 | 0.504825 | 0.493034 |
| Dense | **0.868421** | **0.780702** | 0.205263 | 0.674269 | 0.657748 |

На расширенном наборе `dense` получил наибольшие значения Hit@5 и Recall@5. Метод `hybrid_rerank` лидировал по Precision@5, MRR@5 и nDCG@5. Таким образом, в пределах данного набора плотный поиск показал более высокое покрытие релевантных фрагментов, указанных в qrels, а гибридное переранжирование — более высокие значения метрик, чувствительных к качеству порядка результатов.

Парный bootstrap сравнивал исключительно BM25 и `hybrid_rerank`:

| Метрика | Разность `hybrid_rerank - BM25` | 95%-й доверительный интервал | Двустороннее значение p |

| nDCG@5 | +0.191071 | [0.120123; 0.264414] | < 0.0001 |

Интервалы для обеих метрик не включают ноль, что поддерживает вывод об улучшении относительно BM25 в рамках 114 синтетических запросов и данного протокола. Этот вывод остаётся разведочным из-за происхождения набора. Bootstrap-сравнение с `dense` не проводилось, поэтому различие между `hybrid_rerank` и `dense` не имеет опубликованной статистической проверки.

## 5. Сравнительная интерпретация результатов

Интерпретация результатов требует различать покрытие и качество ранжирования. Hit@5 показывает, удалось ли найти хотя бы один релевантный результат в первой пятёрке, а Recall@5 характеризует долю релевантных фрагментов, указанных в qrels, которые были получены в первых пяти позициях выдачи. Эти показатели прежде всего отражают покрытие. MRR@5 представляет среднее значение обратного ранга первого релевантного результата с ограничением рассмотрения первыми пятью позициями, а nDCG@5 учитывает расположение релевантных результатов в ранжированном списке; поэтому они характеризуют качество порядка. Precision@5 отражает концентрацию известных релевантных результатов в фиксированном окне из пяти позиций.

В обоих наборах `dense` продемонстрировал сильные показатели покрытия. В B3 он одновременно лидировал и по метрикам качества ранжирования. В расширенной разведочной оценке `hybrid_rerank` получил наибольшие Precision@5, MRR@5 и nDCG@5, тогда как `dense` сохранил лидерство по Hit@5 и Recall@5. Это различие показывает, что понятие «лучший метод» нельзя использовать без указания конкретной метрики и набора данных.

Первичный B3 и расширенную оценку нельзя смешивать, суммировать в набор из 150 запросов или представлять как две части одного статистического эксперимента. B3 содержит 36 запросов с неравномерным языковым распределением и недостаточно документированным происхождением qrels. Расширенная оценка содержит 114 синтетических запросов с равномерным распределением по языкам, проверкой с помощью ИИ и отдельными правилами экспорта. Различия между числовыми результатами двух наборов могут быть обусловлены их конструкцией и не должны интерпретироваться как улучшение системы во времени.

Разрезы по языкам и категориям являются описательными. В B3 английская группа включает 9 запросов, русская — только 4, а категории содержат от 3 до 7 запросов. В расширенном наборе каждый язык представлен 38 запросами, но категории имеют неодинаковые размеры от 3 до 15. Отдельные статистические сравнения по языкам и категориям не выполнялись. Поэтому эти разрезы не позволяют делать выводы о преимуществе метода для языка, категории или реальной группы пользователей.

В трассах расширенной оценки зарегистрировано 9 состояний `empty_results` и 561 состояние `evaluated`. Состояние `empty_results` означает, что конкретный метод не вернул результатов для отдельного запроса. Оно влияет на метрики, но само по себе не является технической ошибкой retrieval. Опубликованный счётчик `retrieval_error_count` равен нулю для всех методов.

## 6. Ограничения исследования

При интерпретации результатов необходимо учитывать следующие ограничения.

1. Первичная оценка B3 включает только 36 запросов, что ограничивает стабильность агрегированных оценок и возможность широкого обобщения.
2. В B3 используется бинарная релевантность; возможные степени полезности фрагментов не моделируются.
3. Происхождение qrels B3, число и квалификация разметчиков, процедура разрешения разногласий и межэкспертное согласие документированы недостаточно.
4. Расширенный набор создан синтетически из тем и активных фрагментов корпуса и не представляет независимо собранные запросы реальных студентов.
5. Проверка расширенного набора выполнена с помощью ИИ и не является независимой человеческой аннотацией.
6. Генерация запросов на основе фрагментов, которые затем используются в qrels, может вызывать лексическую утечку и смещение, обусловленное способом построения набора.
7. Qrels расширенного набора были получены и проверены относительно активного корпуса. Это может сделать сложность задач отличной от сложности реального пользовательского поиска и благоприятствовать фрагментам-источникам.
8. Из 132 синтетических кандидатов 18 записей со статусом `pending` исключены. Результаты не характеризуют эти случаи и не должны описываться как оценка всех 132 запросов.
9. Категории распределены неравномерно; малые размеры категориальных групп делают их оценки нестабильными.
10. Расширенный набор не является официальным оценочным набором, независимо подтверждённым эталоном или набором с завершённой человеческой разметкой.
11. Ни первичные, ни разведочные результаты нельзя непосредственно обобщать на реальные обращения студентов, другие корпуса, университеты или условия эксплуатации.
12. Парный bootstrap в обоих наборах сравнивает только BM25 и `hybrid_rerank`. Статистическое сравнение с `dense` отсутствует.
13. Оценка retrieval не измеряет фактологическую достоверность сгенерированных ответов, удобство интерфейса, скорость решения пользовательской задачи или влияние системы на культурную и социальную интеграцию.
14. Проверена конкретная Windows CPU-конфигурация с зафиксированными snapshots; переносимость результатов на иные программные и аппаратные окружения отдельно не оценивалась.

## 7. Обновлённая гипотеза

Предлагаемая формулировка гипотезы:

> В пределах исследуемого административно-образовательного корпуса применение гибридного поиска с кросс-энкодерным переранжированием может повысить MRR@5 и nDCG@5 по сравнению с BM25. При этом ожидаемый эффект зависит от состава запросов и выбранной метрики; гипотеза не предполагает универсального превосходства гибридной схемы над плотным поиском.

Проверяемая статистическая часть гипотезы ограничивается парным сравнением BM25 и `hybrid_rerank` по MRR@5 и nDCG@5. Результаты B3 поддерживают эту ограниченную гипотезу для 36 запросов. Расширенная оценка даёт согласующееся, но исключительно разведочное свидетельство на 114 синтетических запросах, проверенных с помощью ИИ. Превосходство `hybrid_rerank` над `dense` не является частью подтверждённого статистического вывода.

## 8. Обновлённый вывод

В работе реализована модульная система информационного поиска, включающая поиск по ключевым словам, BM25, плотный мультиязычный поиск, объединение результатов методом RRF и кросс-энкодерное переранжирование. Воспроизводимая автономная оценка подтвердила фактическую активацию нейросетевых компонентов без сетевых обращений и без fallback на BM25.

Первичная оценка B3 на 36 запросах показала, что плотный поиск имеет наибольшие глобальные значения Hit@5, Recall@5, Precision@5, MRR@5 и nDCG@5. Гибридный поиск с переранжированием улучшил MRR@5 и nDCG@5 относительно BM25; это сравнение поддержано парным bootstrap. Вместе с тем `hybrid_rerank` не превзошёл `dense` по глобальным значениям B3, а статистическое сравнение этих двух методов не проводилось.

В отдельной разведочной оценке на 114 синтетических запросах, проверенных с помощью ИИ, `dense` лидировал по Hit@5 и Recall@5, а `hybrid_rerank` — по Precision@5, MRR@5 и nDCG@5. Эти результаты указывают на различие между покрытием и качеством порядка результатов в пределах данного набора. Они не превращают расширенный набор в официальный оценочный набор и не доказывают универсальное преимущество одного метода.

Интерпретация результатов расширенного набора ограничена возможной лексической утечкой, формированием и пересмотром qrels на основе корпуса, отсутствием независимой человеческой аннотации, а также малыми и неравномерными по объёму категориальными группами. Из 132 синтетических кандидатов 18 записей со статусом `pending` были исключены. Поэтому результаты имеют разведочный характер и не должны обобщаться за пределы исследуемого корпуса и протокола.

Таким образом, технический вклад работы состоит в реализации и воспроизводимом сравнении нескольких конфигураций retrieval, включая плотный поиск и гибридное переранжирование. На основании доступных данных нельзя назвать один метод безусловно лучшим для любых запросов и корпусов. Для более сильных выводов необходимы независимо собранные реальные запросы, документированный протокол человеческой оценки релевантности, несколько компетентных аннотаторов, оценка согласия между ними и заранее определённые статистические сравнения, включая сравнение `hybrid_rerank` с `dense`.
